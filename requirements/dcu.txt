# Runtime requirements for Hygon DCU (Z100 / gfx906) boards running DTK.
#
# This mirrors requirements/rocm.txt, but the vendor stack replaces the
# community ROCm 7.2 wheels:
#
#   * no `--extra-index-url https://download.pytorch.org/whl/rocm7.2`: a DTK
#     host must never resolve a community ROCm wheel, because DTK's HIP
#     runtime and its rocBLAS/hipBLASLt/MIOpen/RCCL backends differ from the
#     community ones and the two stacks are not ABI compatible;
#   * `torch`/`triton` come from the DTK 26.04 (DAS 1.8.5) direct links
#     instead of torch==2.11.0+rocm7.2 / triton-rocm==3.6.0;
#   * `amdsmi==7.0.2` is dropped: DTK ships its own hy-smi and the DTK Python
#     stack has no `amdsmi` module (vLLM falls back at runtime, see
#     vllm/platforms/rocm.py and vllm/platforms/hygon_dtk.py);
#   * `torchvision`/`torchaudio` are dropped as well: the DTK download tree
#     publishes no wheels for them, and both are optional at vLLM runtime
#     (vllm/multimodal/audio.py wraps the import in PlaceholderModule).
#
# The vendor wheels are cp310-only and manylinux_2_28, so Python 3.10 on a
# glibc >= 2.28 host is required.
