## 0. 三句话

1. **S79 剩下的那 2 行"M>1 确定性数值错"，不是内核 bug，是探针喂错布局；
   但顺着它挖出一个真的宿主 bug**：`nkv` 取自 `key_cache.size(2)`，
   在真实 int8 布局里那是 block_size，`grid.y` 被放大成 832、Q head 越界。
   修掉（fix2）之后，sdot4 在 M=1…16、三个 seed、两种布局下**全部逐位正确**。
2. **修好也不够快**：131k prefill 内核 1030.5 → 1024.3 ms（−0.6%），
   离 +3% 门差 30 ms。**sdot4 不进生产，`v_dot4` 指令形态闭案。**
   decode 形状有真收益（−15.8%），留作后续 KV int8 部署的起点。
3. **MIN_CTX 8192 过门并已固化**：16k −20.3%、32k −11.3%、8k −6.2%、
   131k −1.6%。生产重启后 131k 是 **274.6 s**（原 279.2 s）。

## 1. A 线：sdot4 收官

### 1.1 归因表（详见 `.s80/wp0-suspect-ledger.md`）

| 嫌疑 | 判定 | 证据 |
|---|---|---|
| S1 `ks_lds` 尾段残留 | 排除 | one-hot K / const-K 用例 ≤1e-6 |
| S2 Q prologue `shfl_xor(16)` 跨 wave | 排除 | 逐 pair dump 原始 Q/amax/scale/rtoken/rhead，无跨行 |
| S3 `k_scale_cache` 接线 | 排除 | dump 的 scale 与 host 量化器逐 pair 一致 |
| S4 `v_dot4_i32_i8` 截断 | 排除 | const-K=127 手算一致；KL 3.4e-5 |
| **S5（新）宿主 `nkv` 取错维度** | **成立，已修** | 真实布局 `(blk, nkv=1, slot, 520)` 下 `size(2)=832` |

关键实验（同一内核、只换输入布局）：

```
fix1  layout=s79   M=2  worst_abs_err=2.635e+02   ← S79 记录的"确定性错"
fix1  layout=prod  M=2  worst_abs_err=2.840e-05   ← 真实布局，逐位正确
```

### 1.2 fix2 数值门

- `M ∈ {1,2,3,4,6,8,12,16} × seed{21,73,101} × 布局{s79,prod}` = 48 例，
  全部 `|d| ≤ 8e-5`；
- 真实布局 vs host int8 参考（同口径量化 Q）：相对误差 3.0e-4~1.6e-3；
- one-hot-V 直接测 KL：**3.4e-5 ~ 6.7e-5**（门 1e-2，余量两个数量级）。

> 勘误：`.s73/kv_real_layout_test.py` 报 7.9e-3 "FAIL" 是判据问题——它用
> 未量化的 Q 做参考，把 int8 Q 量化本身算进了误差。

### 1.3 计时（ms，中位）

| 形状 | fp16 T1 | sdot4 fix2 | 变化 |
|---|---:|---:|---:|
| prefill 8k | 65.7 | 64.3 | −2.1% |
| prefill 32k | 257.3 | 257.5 | +0.1% |
| prefill 64k | 512.6 | 514.2 | +0.3% |
| **prefill 131k** | **1030.5** | **1024.3** | **−0.6%** |
| decode M=1 @131k | 0.594 | 0.500 | **−15.8%** |
| verify M=12 @131k | 2.025 | 1.940 | **−4.2%** |

ISA：vgpr 121→103、spill 0、LDS 32768→28800、`v_dot2` 448→0、
`v_dot4` 0→224。红线全过。

### 1.4 两处结论修正（对 S79）

1. **"双缓冲缺屏障"不是失败原因**：去掉 fix2 上第二道屏障，M=1…16 仍全绿。
   那道屏障是**性能必需品**（去掉后 131k 慢 2.7%、8k 抖动到 131 ms），保留。
2. S79 的"残余确定性错"整体归因于 **S5 宿主维度 bug + 探针布局**，
   与内核内环无关。

### 1.5 裁决

**不采纳。** 门是 ≤993.6 ms，实测 1024.3 ms。省下的 QK 指令时间被 PV 段
的 int8→fp16 反量化吃掉。`v_dot4` 指令形态路线落排除表，注意力内核
形态议题正式终结于 **5.72 TF/s**（fp16 T1）。decode 侧若上 KV int8，
fix2 是逐位正确的起点。
