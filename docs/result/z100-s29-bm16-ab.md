## 2. parity 板（用户裁决项的证据）

`perf1_e2e_bench.py --mode parity` 8 prompt 长度（256/439/512/1024/2048/4096/
6144/7168）× 64 tok × 2 reps，两臂各一轮，`perf1_e2e_parity.py` 对拍
（`.s29/parity-bm16-ctl-vs-arm.json`）：

- **verdict = confirmed：16/16 cases token 流逐位相同，零翻位**；
- 臂内确定性全部成立（8 长度 × 2 reps 逐位一致 × 两臂）；
- top-1 logprob 值漂移：16 cases 最大 0.2255 nat（同为同 token 的数值漂移，
  **非翻位**；翻位协议的 Δlogprob(top1,top2) < 0.05 nat 条件因零翻位未触发）；
- 96-token 7469-doc 贪心流（capture.py，top-5 logprobs）：BM16(r1) 与 control
  (pin3) **逐位相同**，零 top-1 翻位，max |Δtop1 logprob| = 0.0213 nat。

## 4. 给裁决的要点

- 收益：step p50 −3.1 ms（−3.3%），与 S24 per-op 预期一致；32k/长上下文
  ITL 收益（S24 的 −7.3%）本 WP 未单测（现网口径 7469 文档）。
- 风险：parity 板干净（零翻位），数值风险低于 A1/draft-3D 当时水平；
  logprob 值漂移上限 0.2255 nat 大于 A1 的 0.0236——按
  `docs/perf/ATTN-OPT-20261025.md` §3 协议属"无翻位的值漂移"，不触发例外。
- 未决：accept 分布（BM16 两重启两世界）受残存彩票污染，无法归因 BM16
  本身；若采纳，建议采纳后按 WP-A 的 N-restart 协议补 4 重启 accept 分布。
- 回滚：不加 export 即回滚（本 WP 未改任何生产文件）。
