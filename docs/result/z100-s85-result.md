# S85 结果：QK 段 T1 移植（int8 内核补上"一次 Q 读服务 32 键"）

日期：2026-11-12。状态：**出口 A，已采纳上生产**。
设计：[`../design/z100/s85-qk-t1-port/z100-s85-qk-t1-port-design.md`](../design/z100/s85-qk-t1-port/z100-s85-qk-t1-port-design.md)
施工：[`../design/z100/s85-qk-t1-port/z100-s85-qk-t1-port-construction.md`](../design/z100/s85-qk-t1-port/z100-s85-qk-t1-port-construction.md)
台账：[`.s85/README.md`](../../.s85/README.md)

## 一句话

**int8 注意力内核每处理一个 16 键的块都要重读一遍 Q；把 fp16 内核 S77 的
"一次 Q 读服务 32 键"结构搬过来之后，131k token 的注意力 kernel 从
882.5 ms 降到 794.9 ms（−9.9%），长上下文首字时间从 248.7 s 降到
235.3 s（−5.4%），而输出与改动前逐位一致。已上生产。**

## 1. 改了什么（一句话版）

原来：每 16 个键取一次 Q（8 条 128-bit LDS 读），Q 的读取占内核每块 LDS
读流量的 1/3。

现在：每 32 个键取一次 Q，用同一份 Q 同时算两块分数（两条独立的整数点积
链）。K 缓冲从"16 键双缓冲"改成"32 键单缓冲"（8 KB 不变），V 仍是 8 KB
单缓冲，Q 缓冲不变 —— **LDS 总量 20608 B、每 CU 3 个线程块，占用率一点没降**。

选这个不对称形态的原因：V 的 int8 行只有 256 B，若照搬 fp16 的"32 键 V 单
缓冲"会让 V 涨到 16 KB，总量突破 21 KB 阈值，线程块从 3 掉到 2，把 S83 拿
到的占用收益全吐回去。

相同 ⇒ 下游 logits 逐位相同 ⇒ 采样与接受判定必然相同。

协议修正记录（重要）：用固定 seed 的 token-id 提示会命中前缀缓存，131k 首字
被压到 5.3 s —— 初测差点把这个假数字当成基线。**服务级长上下文测量必须每次
换提示内容**，本轮已改为每请求换 seed。

## 6. prefill 各阶段速度（131k，采纳态实测）

工具 `.s82b/prefill_stages.py`，torch profiler 覆盖整条请求，四个 TP rank
lockstep（总时长均 234.9 s）。被测 = 采纳态 `.so` `188b6e3a`。

- 首字时间：**235.78 s**（profiler 开销 ≈0.2%，与不带 profiler 的 235.3 s 一致）；
- kernel 合计 234.9 s ⇒ **99.6% 的时间在 GPU kernel 里**，无 CPU 空转；
- 整条 prompt 吞吐 **556 tok/s**（131072 / 235.8 s）。

| 阶段 | 代表 kernel | 耗时 (s) | 占比 | 阶段吞吐 |
|---|---|---:|---:|---:|
| **注意力（prefill 内环）** | `attnd_inner_kvsdot4_kernel` | **125.5** | **53.4%** | 1044 tok/s |
| **GEMM** | fp8-emu GEMM / Cijk / Tensile | **82.2** | **35.0%** | 1595 tok/s |
| allreduce | nccl / custom AR | 10.2 | 4.4% | — |
| dequant / copy | fp8 dequant、convert、CatArrayBatchedCopy | 6.6 | 2.8% | — |
| GDN | chunk gated delta / conv | 5.4 | 2.3% | — |
| other | 其余 | 3.8 | 1.6% | — |
| norm | rms / rope / silu | 0.9 | 0.4% | — |
| attn_reduce | `reduce_segments` | 0.2 | 0.1% | — |

与 S82-b 那次拆解相比，注意力的占比从 59.2% 降到 53.4%，绝对耗时按同口径
也降了约 9% —— 与内核计时一致，说明收益原样穿透到了服务级，没有被框架开销吃掉。

## 8. 结论与转场

- 出口 A：QK 段"读复用"这条线走完，int8×int8 + Q 复用就是这块内核的形态终点；
- 注意力 kernel 层全部收口（S84 已闭 PV 段于 fma_mix，S85 闭 QK 段于 T1）；
- 下一个大头是 GEMM（35.0%）与 allreduce（4.4%）—— 注意力的份额已经从
  59.2% 降到 53.4%，继续在注意力上抠的边际收益明显变小；
- 顺带臂 B1（staging 地址链瘦身）/ B2（p-path 常数折叠）按设计图是"主刀
  过门后可选"：本轮主刀收益已远超预期（−9.9% vs 预期 −3~6%），B1/B2 的
  预期只剩 −1~2%，未做，挂入排除表备查。
