## 结论

1. **出口 B**：四臂 131k 中位对 `phsr` 分别为 `sr2 +0.158%`、
   `addr +0.459%`、`tail +0.247%`、`wcnt +0.241%`；无臂过采纳门
   （≤ −0.5%），也无臂触排除线（≥ +0.5%）。**指令瘦身方向判边际耗尽**，
   按图转"PV LDS 布局重构"或"放宽逐位同口径"两个独立立项。
2. 四臂五形状**逐位同**，静态硬门全绿（spill 0 / LDS 20608 / bucket 20992 /
   ctas 3 / vgpr ≤71 / total_inst ≤1585）。`phsr` 仍是最佳候选
   **872.08 ms（−1.17% vs dot2）**；S98 收工后用户裁决采纳进生产
   （见 [`deploy-adopt`](../../.s97/deploy-adopt.md)）。
3. 归因：`sr2` 只省 1 条静态指令（守卫被编译器重组，HA2 未达）；
   `addr` 保守版净 +8 条、sgpr +2；`tail` 体 +4 条、v_cmp +2、vgpr 贴 71；
   `wcnt` 把 PV 读的 `s_waitcnt` 30→20 条但 wall 反升，与 LDS 延迟暴露一致
   （臂级 stage 归因属可选，未做）。

## WP0.3 动态归因要点

- 真回边 `0xff60`（函数基址 `0xf100` + 符号偏移 `0xe60`），主循环体
  **823 条/迭代**；设计图 `0xe60..0x112bc` 的 1,475 条含 652 条 Q prologue，
  已按真回边重算，臂的收益预期随之下调。
- `v_mov` 54 条/迭代，v→v 仅 6 条 → 按图不立 `mv`。
- `s_waitcnt` 67 条/迭代；PV 读近邻等待 30 条。

## 与图的偏差 / 后续

1. 回边口径修正（见上）。
2. `addr` 指针递推版静态 1,617 条破线（sgpr 78），按图回退保守版。
3. `tail` 的 `vgpr=71` 已贴红线，后续不应再叠加寄存器压力。
4. 四臂全平/微负且静态未能实质瘦身 → 不再在"删指令"上做第三轮；
   PV 的 37.6% 与 load 的 21.2% 才是下一个结构性目标。
