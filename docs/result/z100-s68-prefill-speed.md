1. **首 chunk（~7.5k tok）恒定 ~8.3 s**：权重 GEMM + AR + norm 等
   固定项为主，注意力尚浅，任何 ctx 都要付；
2. **深 ctx chunk 逐级变贵**：131k 时中间 chunk 达 27.7 s/chunk
   （≈3.7 tok/ms），注意力随 KV 深度线性增长，与 S63 内核账一致；
3. **16k 门槛两侧无明显断崖**：16384 的首 chunk（2D）8279 ms 与
   8192 全程 2D 的 7846 ms 差 ~0.4 s——B2 的"降门槛"立案不成立。
