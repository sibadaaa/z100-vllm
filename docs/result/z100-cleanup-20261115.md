```
TypeError: chunk_gated_delta_rule() got an unexpected keyword argument 'output_checkpoints'
```

`vllm/third_party/flash_linear_attention/ops/chunk.py`（09:38）在**上次成功启动
（09:31）之后**被修改，属于 S100b-B1（mid-prefill state 导出）的半成品；
且改错了实现——运行时 `fla_chunk_gated_delta_rule` 来自
`vllm/model_executor/layers/fla/ops/chunk.py`，而不是 `third_party/`。

处理：**只回退这两个文件**到 HEAD（其余 S100b 改动原样保留），WIP 已存为补丁：

```
archive/cleanup-20261115/b1-gdn-checkpoint-wip.patch   (111 行)
```

回退后重启：health 200（260 s），`FP 71c3af949b564865` 与改动前一致，
MTP k=2 正常，冒烟生成中文连贯。B1 要续做，需把 `output_checkpoints`
接到 `model_executor/layers/fla/ops/chunk.py` 的 `chunk_gated_delta_rule`
（并同步 `ChunkGatedDeltaRuleFunction` 的返回值契约），否则任何重启都会再崩。
