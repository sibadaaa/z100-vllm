## 五、口径说明

- 内核时间取 rank0 的 chrome trace kernel 事件求和；四 rank 总和偏差 <1%
  （TP 每步有 all-reduce 对齐）。
- TTFT 为服务端流式首 token 时刻减请求发出时刻，含排队、调度、跨步开销；
  因此 TTFT 略大于内核总时间（131k 差 1.2 s、64k 差 0.8 s）。
- 冷缓存：每次用不同 seed 生成 prompt，避开 `--enable-prefix-caching` 命中
  （命中会把 8k 从 9.8 s 压到 2.5 s，严重失真）。
- profiler 窗口会冻结服务（本次两次命中，S55 §6 已记录），采 trace 必须
  预留重启窗口。
