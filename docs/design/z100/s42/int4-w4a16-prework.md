# INT4 w4a16 GEMV 预研(只做可行性,不动代码)

> 2026-10-31。背景:S41/S42 后 fp8 GEMV 内核结构空间已穷尽(组发射、
> 环深、双缓冲、宽 lane、位技巧、LDS 消除、a-reg 全谱证伪,见
> `.s41/b-close.md`、`.s42/b0-verdict.md`);剩余的字节级杠杆只有换权重
> 位宽。本文给 INT4 w4a16 的收益上限、技术路径、门的重定义与工作量,
> **立案前置条件:质量门由模型侧裁决**。

## 1. 收益上限(账)

| 项 | fp8 现役 | INT4 w4a16 |
|---|---|---|
| 权重字节/元素 | 1 B + fp32 scale/128 摊销 ≈ **1.03 B** | 0.5 B + scale 摊销 ≈ **0.53 B**(对称,zp=0) |
| 物理 GB/s 口径(wholea 实测) | 643 GB/s | 结构同骨架,假设持平 |
| **元素吞吐** | 623 G-elem/s | **~1.21 T-elem/s(×1.94)** |
| GEMV 桶(256 发,中位) | 11.15 ms/step | **~5.8-6.5 ms/step(−40~48%)** |
| 单流(当日带 39 t/s) | — | ~46-52 t/s(折算上限,服务折损另计) |

字节减半是**平方关系里最硬的一档**:2 FLOP/B 的算术强度下,内核效率
损失 10% 只吃掉一半收益,桶仍能到 ~6.5 ms。

## 2. 量化管线选择

- **推荐:GPTQ,group=128,对称(zp=0),actorder 不用**(与现役
  per-block-128 scale 结构完全对齐,折算乘法序不变)。
- 现成产出:HF `auto-gptq`/`llm-compressor` 权重包(int32 pack 沿 K,
  8 nibble/dword);校准集 512 条即可。
- AWQ 需激活校准且无 DCU kernel 优势;RTN 只作数值基线对照。
- scale 存储:`q_s [N, K/128]` fp16(或 fp32),替换现 `w_s` 语义。

## 3. 内核路径(在 wholea 骨架上换载荷)

- **遍历几何重切**:lane 的 16 B uint4 = 32 个 INT4 元素(fp8 是 16)。
  slice 从 1024 元素改 **2048 元素**(每行 64 uint4 → 64 lane 满载,
  与现 lane→chunk 满载结构对齐);A 读变为每 lane 每 slice 4×uint4。
- **LUT 缩到 16 entry × fp16 = 32 B = 8 寄存器——LUT 可寄存器驻留**,
  widening 零 LDS 流量。配合 S42 a-reg 的教训(寄存器预算要留给数据),
  INT4 内核有机会做到**除 scale 外零 LDS**(S33 的 4-way bank 冲突一章
  以"消灭查表"而非"消除冲突"收尾)。
- 宽展两种实现都留:16-entry 寄存器 LUT 查表,或无查表位技巧
  (nibble 符号扩展 → cvt,整数 ≤2048 在 fp16 内精确)。
- scale 折算:lane 的 32 元素块不跨 128 组边界(`l*32 % 128 ∈ {0,32,64,96}`),
  每 lane 每 slice 一次 scale 乘——与 fp8 的 per-block 折算同构。
- **位同空间**:换权重 = 非位同变更,不再走 torch.equal;内核内部的
  确定性(同输入同输出)仍按构造保证。

## 4. 门的重定义(关键差异)

| 门 | fp8 内核轮(S33-S42) | INT4 轮 |
|---|---|---|
| 内核位同 | torch.equal | 不适用(权重变了) |
| 内核数值 | max\|Δ\|≤3e-4 | RTN 基线对照(GPTQ 应优于 RTN) |
| 服务数值 | S29 板 0.2255 nat / 0 错位 | **S29 板必然超限 → 换门:贪心流语义对照(禁毒/禁重复/长度分布)+ 任务小集** |
| 模型质量 | 不适用 | **PPL(wikitext-zh/en + 自定义域集)相对 fp8 基线 ≤ 用户阈值(建议先按 +3% 试)** |
| 性能门 | 窗口 +6% | 物理字节口径 GB/s ≥ 550(等效元素吞吐 +76%) |

## 5. 集成点

- loader:HF GPTQ pack 格式 → per-stage 分片(与现 w_s 分片同路径);
- op:扩展现 `fp8_emu_gemm_block_w8a16` 加 `qdtype` 参数(新模板分支),
  或独立 `w4a16_gptq_gemm`;env `VLLM_DCU_INT4_GEMV=1`(默认 0);
- 形状门:沿用 `wholea_shape_ok` 类 LDS 预算(A 不再整行驻留,预算更松);
- 部署:S43 全流程(D0 探针 → 内核 → 三门 → ABAB),与 S41 同构。

## 6. 探针先行(立案后第一件事,0.5h)

`widen_tax` 加 mode 19 "S int4":wholea 骨架 + RTN 合成量化权重
(对现 fp8 权重做 group-128 对称 RTN)+ 寄存器 LUT 宽展,测物理
GB/s。**门:物理 GB/s ≥ 550**;不过则整轨关档(与 S41 B0 同纪律)。

## 7. 工作量与风险

| 项 | 估时 |
|---|---|
| 探针 mode 19 + 判定 | 0.5d |
| loader + packer + 权重转换 | 1-1.5d |
| 内核(骨架换载荷 + LUT-reg + 折算) | 1-1.5d |
| 量化跑模型 + PPL/任务评估 | 1d |
| 三门 + ABAB + 部署 | 0.5d |
| **合计** | **~4-5d** |

- 最高风险 = **质量门**(27B 对称 GPTQ 典型 PPL +1~3%,是否可接受由
  模型侧裁决;非对称/zp 可再买回一点,代价 0.03 B/元素)。
- 次风险 = INT4 lane 几何重切引入新访存形态(探针先行 kill-fast 可控)。
- DTK 上 `__builtin_nontemporal_load`/cvt 的 codegen 已有 S42 经验。

## 8. 决策点(立案前置)

1. 用户接受 PPL/质量阈值(建议先以 +3% 试跑评估再定);
2. 校准集来源(生产 prompt 分布采样 512-1024 条即可);
3. 目标场景确认仍是单流时延(若是吞吐,continuous batching 优先级更高)。
